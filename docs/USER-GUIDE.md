# 使用说明与常见问题

## 第一次运行

从仓库 Releases 下载 Windows x64 便携 ZIP，完整解压后双击 `VideoArchive.exe`。保留 `tools` 与 `licenses`，无需安装 .NET、Python 或 FFmpeg。第一版面向 Windows 11，不需要账号，主程序不联网处理素材。

启动时选择源目录；硬件检测同时进行。首次检测会运行短帧编码，之后在电脑、驱动、系统、会话环境和 FFmpeg 内容未变化时复用缓存。远程桌面或驱动变化可能使缓存失效。

## 备份流程

1. 选择源目录。默认输出 `源目录名_已压缩`，与源目录并列。例如 `D:\素材\旅行` 输出到 `D:\素材\旅行_已压缩`。
2. 如需其他位置，勾选“输出到其他文件夹”，选择存放位置；程序在其中创建完整带后缀的备份目录。
3. 选择预设，检查最终参数摘要。智能推荐按最终输出尺寸、帧率计算；最高1080P是独立选项。
4. 扫描，查看目标、估计容量、操作和原因。参数改变后重新计算计划，未变化的媒体信息复用缓存。
5. 时间码异常时，在自动弹出的窗口勾选文件，再点击绿色“原样备份”或紫色“舍弃时间码”。可全选、单选或仅勾选待决定。全部决定后返回任务；“稍后处理”允许先查看计划，但不能启动尚未决定的任务。
6. 开始备份。暂停会完成当前文件后暂停队列；取消会停止当前编码并清理临时输出。历史任务可继续，已完成项经过核验后跳过。
7. 查看实际报告，打开输出目录，或导出 CSV / JSON。

## 推荐方案

平衡备份为 ×1.0；空间优先 ×0.75；高质量 ×1.25；还可选择 ×1.5。系数调整工程估算码率，不承诺特定素材的主观画质。10-bit SDR不额外加码，常规HDR使用 ×1.25。

码率和帧率是上限：10 Mbps面对15 Mbps上限原样复制；45 Mbps / 30 fps面对20 Mbps / 60 fps仍输出30 fps。默认仅因码率触发时还需满足10%容差和15%预计收益。尺寸降低、限帧或统一格式属于明确转换要求。

## 为什么仍有文件原样备份？

已满足规格、码率未知、未验证容器、动态HDR、透明通道或其他无法保护的信息均可能触发原样备份；具体原因显示在扫描表中。成品实际更大或保护校验未通过时，也可能改为原文件备份。

压缩时特殊数据轨仅尝试保留 `tmcd`；其他相机数据轨会移除。时间码描述未验证时允许选择舍弃时间码，音轨、字幕及可支持元数据仍保留。这项选择不会取消其他素材保护规则。原样备份保留整份源文件。

高于8-bit且为4:2:2 / 4:4:4等YUV素材按要求转换为HEVC Main10 / 10-bit 4:2:0，即使普通预设为AV1或8-bit。所选设备不支持HEVC 10-bit时说明原因并原样保留。

## 扫描与执行速度

首次扫描最多并行探测4个文件；HDR、10-bit和限帧检查会读取额外信息。缓存依据源路径、大小、修改时间与探测引擎复用。改变素材、FFprobe或缓存版本会重探测。

GPU加速主要作用于编码；哈希、文件复制、解码校验仍可能受CPU和磁盘影响。每个转码成品完整解码验证，复制核对SHA-256，因此网络盘或大量素材的总时间可能明显长于单独编码。

## 壁纸与本地数据

顶部“自定义壁纸”或设置页可导入PNG、JPG/JPEG、BMP、GIF并调整显示强度；GIF静态显示。程序复制图片到本机数据目录，原图删除不影响已保存壁纸。支持恢复默认背景。

默认数据目录为 `%LOCALAPPDATA%\VideoArchive`：

| 路径 | 内容 |
| --- | --- |
| `settings.json` | 预设、默认方案、引擎路径、外观 |
| `capabilities-v1.json` | 编码能力及环境指纹 |
| `probe-cache-v2.json` | 媒体探测缓存 |
| `jobs/` | 计划、执行状态、参数快照和历史 |
| `appearance/` | 导入壁纸的本地副本 |

设置和历史可能包含素材路径及设备信息，反馈时应先检查并移除私人内容。备份软件文件夹不会自动包含上述本地配置。

## 故障处理

- **编码设备不可选**：检查驱动与FFmpeg，在设置中重新检测；硬件失败会显示具体原因，不自动换方案。
- **旧任务要求重扫**：计划版本与当前保护规则不一致，重新扫描可生成兼容计划。
- **磁盘不足或权限不足**：检查源、输出和临时输出所在盘；失败项可在处理后重试。
- **相同或嵌套目录被拒绝**：选择相邻输出目录或独立存放位置，避免递归备份。目录联接、符号链接不跟随。
- **系统阻止启动**：当前版本未做Windows代码签名。核对Releases来源及SHA-256；不要关闭系统保护。
